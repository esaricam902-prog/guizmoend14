Guide : comment fonctionne le portail

Organisation du dépôt, ajout d'un jeu et mise en ligne

1 Structure du dépôt 

📁 guizmoend14/
├── 📄 index.html              <-- ce portail
├── 📁 gizmo-src/              <-- codes Gizmo d'origine (app1.tsx … app14.tsx)
├── 📁 tools/
│   └── 📄 gizmo_to_html.py    <-- convertit gizmo-src/ en pages HTML
└── 📁 apps/
    ├── 📄 app1.html … app14.html  <-- pages générées, une par jeu
    ├── 📄 gizmo-runtime.js    <-- remplace @gizmo/runtime
    ├── 📁 assets/             <-- sons et images servis en local
    └── 📁 thumbs/             <-- aperçus des jeux pour le portail

2 Ajouter ou mettre à jour un jeu

  1. Copie le code exporté depuis Gizmo dans gizmo-src/appN.tsx, sans le modifier.
  2. Pour un nouveau jeu, ajoute son titre dans APPS en haut de tools/gizmo_to_html.py.
  3. Lance la conversion :
python3 tools/gizmo_to_html.py

Enfin, ajoute une entrée dans la liste GIZMO_APPS de ce fichier index.html :

{
  id: 15,
  title: "Mon nouveau jeu",
  description: "Une phrase qui décrit le jeu.",
  path: "apps/app15.html",
  thumb: "apps/thumbs/app15.webp",  // optionnel
  icon: "ph-game-controller",       // icône Phosphor
  color: "from-pink-500 to-rose-600",
  badge: "Fun"                      // catégorie
}

3 Mettre en ligne avec GitHub Pages

Sur GitHub : Settings → Pages, choisis la branche main et le dossier / (root). Le portail sera disponible à l'adresse https://<ton-pseudo>.github.io/guizmoend14/.

Astuce : chaque jeu a son propre lien, par exemple …/guizmoend14/#jeu-3, que tu peux partager directement.
