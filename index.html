Guide : Structure des 14 projets dans GitHub

Comment organiser vos fichiers dans un seul dépôt GitHub Pages

1 Structure recommandée des fichiers sur GitHub

Pour héberger vos 14 applications dans un seul dépôt GitHub (ex: mon-portal-gizmo), organisez vos fichiers comme ceci :

📁 mon-depot-github/
├── 📄 index.html             <-- (CE FICHIER PORTAIL D'ACCUEIL)
├── 📁 apps/
│   ├── 📄 youtube-sim.html   <-- Application Gizmo 1
│   ├── 📄 jeu-2.html         <-- Application Gizmo 2
│   ├── 📄 app-3.html         <-- Application Gizmo 3
│   └── ...                   <-- (Jusqu'à 14 fichiers .html)

2 Comment convertir chaque code Gizmo en fichier HTML ?

Pour chaque lien Gizmo JS, créez un fichier apps/nom-de-lapp.html avec cette enveloppe Babel universelle :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <script src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
  <script src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>
  <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    // Emulateur Gizmo Runtime
    window.gizmoRuntime = { tweaks: () => ({}), performHaptic: () => {} };
  </script>
</head>
<body class="bg-black text-white">
  <div id="root"></div>
  <script type="text/babel">
    const { useState, useEffect, useRef, useCallback } = React;

    // === COLLE TON CODE JS GIZMO ICI ===
    function App() {
      return <div class="p-10">Mon App Gizmo</div>;
    }

    ReactDOM.createRoot(document.getElementById('root')).render(<App />);
  </script>
</body>
</html>
